# App 优化与离线优先在线更新设计

**日期：** 2026-09-13
**项目：** 认知训练 Android App

## 目标

在保留当前离线可用能力的前提下，提升题库分类、每日自适应、训练反馈、Android 运行可靠性和在线内容更新能力，并让关键用户流程可以被自动回归验证。

## 方案

App 继续采用原生 Android WebView 容器，HTML、CSS、JavaScript 和内置 JSON 作为离线基线。在线能力只更新经过校验的 JSON 内容包；不下载或执行远程 JavaScript、HTML 或静默安装 APK。Android 原生桥负责网络请求、私有文件存储和内容包原子替换，网页负责展示、校验内容字段和刷新当前会话。

在线内容更新采用 HTTPS 版本清单、SHA-256 校验、结构校验、临时文件下载和原子替换。内置内容始终可回退，网络失败、校验失败或内容不完整时不影响离线使用。APK 更新只做版本提示和手动下载入口，保留用户对安装行为的控制。

## 模块

### 1. 题库与自适应

- 一级能力统一为：人际判断、沟通表达、亲密关系、边界冲突、自我调节、五维认知。
- 旧 `domain` 保留为 `legacyDomain` 或标签，避免已有进度统计丢失。
- 普通题按照错题、错误类型、间隔复习和近期题族共同加权。
- 第六题使用设备本地日期；维度选择优先考虑低正确率且样本足够的维度。

### 2. 训练报告

报告显示最近 7 天和 30 天的完成率、正确率、错误类型、一级能力和五个维度趋势，并区分原题命中、变体命中和迁移题命中。报告入口放在成长页，避免底部导航继续膨胀。

### 3. Android 运行与安全

- 修复并固化第六题开始检验的点击回归。
- 修复练习子导航测试与弹层清理问题。
- 关闭文件 URL 跨域访问能力。
- 原生网络桥只接受 HTTPS 和允许域名。
- 保持已验证的不可变 PendingIntent、非导出提醒 Receiver 和 cleartext 禁用。

### 4. 在线内容更新

版本清单包含内容版本、最低 App 版本、各数据文件下载地址和 SHA-256。更新流程为：检查清单 → 用户确认 → 下载临时文件 → 校验哈希 → 解析 JSON → 运行内容契约校验 → 写入 App 私有目录 → 原子替换 → 刷新内容。失败时保留旧内容。

### 5. APK 版本提示

版本清单可包含 `latestApkVersion`、`apkUrl` 和 `apkSha256`。发现新版本时在设置页提示用户手动下载；不执行后台安装。正式发布前需固定长期发布签名。

## 验收标准

- 题库分类统一且旧进度仍可读取。
- 第六题从入口到提交答案可自动回归。
- 训练报告在无数据、部分数据和完整数据时均有可读状态。
- 在线更新成功、断网、哈希错误、JSON 结构错误和版本过低均可验证。
- APK 通过编译、签名、离线包同步和内容校验。
- 所有现有结构测试通过，且真实设备缺失时明确报告未完成的设备级验证。
